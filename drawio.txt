===================== ARCHITECTURE FLOW
User Question
     │
     ▼
[ Auth & Role Verification ]
     │
     ├── If Role == 'admin':
     │     Gather: System stats, total users, book inventory, category counts
     │
     └── If Role == 'user':
           Check: Is question asking for admin-only stats?
             ├── Yes ──> Immediate 403 / Rejection response (No AI call)
             └── No  ──> Gather: Available books, categories, user's profile/interests
     │
     ▼
[ Build Prompt with Filtered Context ]
     │
     ▼
[ Call LLM (OpenAI / Gemini) via Laravel HTTP ]
     │
     ▼
Send Sanitized Answer to Client

===================== BACKEND
# 1. تنزيل حزم الـ PHP
composer install

# 2. إنشاء ملف الإعدادات البيئية .env
cp .env.example .env
# (على ويندوز لو الأمر منفعش: copy .env.example .env)

# 3. توليد مفتاح التطبيق السري
php artisan key:generate

# 4. فتح ملف .env وضبط:
# - اسم قاعدة البيانات: DB_DATABASE=ai_library
# - مفتاح الذكاء الاصطناعي: OPENAI_API_KEY=sk-proj-...

# 5. بناء الجداول وحقن البيانات التجريبية
php artisan migrate:fresh --seed

# 6. عمل رابط مجلد الصور العام (مهم جداً للصور المرفوعة)
php artisan storage:link

# 7. تشغيل سيرفر الـ API
php artisan serve
